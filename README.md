# INCORA People

Internal HR application for INCORA; Ukrainian by default with an English option. The shipping web application uses React, vinext, Cloudflare Workers, D1, and private R2.

New developer: start with [START_HERE.md](START_HERE.md). See the [architecture](docs/architecture/OVERVIEW.md), [product map](docs/product/MODULES.md), [current status](docs/project/CURRENT_STATUS.md), and [documentation audit](docs/project/DOCUMENTATION_AUDIT.md). Historical specifications are evidence, not release instructions. Mobile and browser extension are [deferred](docs/roadmap/DEFERRED_AND_ARCHIVED.md).
