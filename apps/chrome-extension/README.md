# INCORA People — Chrome extension (alpha)

> Deferred / archived; not an active release. See [deferred work](../../docs/roadmap/DEFERRED_AND_ARCHIVED.md).

Extension has one responsibility: securely start and stop the employee's work timer.

## Installation from INCORA People

1. In INCORA People, use **Download Chrome extension** at the bottom of the
   left navigation.
2. Extract the downloaded ZIP into a permanent local folder.
3. Open `chrome://extensions` in Chrome or Chromium and enable
   **Developer mode**.
4. Choose **Load unpacked** and select the extracted folder.
5. Pin **INCORA People — Час** in Chrome's toolbar, open it and sign in.

The extension needs only Google sign-in plus start/stop of the work timer. It
does not access browsing history or page contents.

## Before sharing outside the team

Publish a signed package through the Chrome Web Store (unlisted is sufficient)
when the internal alpha moves beyond **Load unpacked**. The downloaded ZIP is
suitable for the internal alpha flow.
