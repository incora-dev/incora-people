# Configuration and secret names (no secret values)

| Name                                                                                     | Purpose                                                        | Scope / setup                                                                                                                                                             |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP_MODE`, `DEMO_USER_EMAIL`                                                            | protected or explicit demo; fixture identity                   | Demo local only; production protected.                                                                                                                                    |
| `AUTH_PROVIDER`, `ALLOWED_EMAIL_DOMAIN`                                                  | Sign-in provider and optional domain allowlist                 | Local/prod build vars; Google and `*` observed in production. Admission still checks provisioned account.                                                                 |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `AUTH_SECRET`                                | OAuth ID, client secret and session/state signing input        | Required for protected Google. ID is build variable; other two use ignored .dev.vars or Worker secret storage. Use separate dev credentials. Never copy prod credentials. |
| `CF_ACCESS_TEAM_DOMAIN`, `CF_ACCESS_AUD`                                                 | alternate Cloudflare Access JWT configuration                  | Optional when Google; only set with explicit alternate-auth design.                                                                                                       |
| `CLOUDFLARE_D1_DATABASE_ID`, `DB`, `FILES`                                               | Vite D1 ID input; runtime D1/R2                                | Blank local placeholder for emulation. Verified IDs/bucket for deploy; bindings set via .openai/hosting.json and Vite.                                                    |
| `PUBLIC_APP_URL`                                                                         | validated canonical URL for email links                        | Set at build; review against deployed value. Distinct from incoming OAuth host.                                                                                           |
| `RESEND_API_KEY`, `INVITATION_FROM_EMAIL`, `EMPLOYEE_INVITATIONS_ENABLED`                | provider credential, verified sender, invitation enable switch | Optional for local disabled; configured production bindings. Use least-privilege current Worker secrets and verified sender authorization.                                |
| `GOOGLE_CHAT_WEBHOOK_URL`                                                                | Google Chat endpoint                                           | Optional hosted secret; URL itself is sensitive. Leave unset for local.                                                                                                   |
| `ANNOUNCEMENT_EMAIL_WEBHOOK_URL`, `ANNOUNCEMENT_WEBHOOK_SECRET`, `INCORA_WEBHOOK_SECRET` | legacy email fallback and secret/alias                         | Optional hosted config; never supply live values locally.                                                                                                                 |
| `ANNOUNCEMENT_CRON_SECRET`                                                               | Internal scheduled delivery authorization                      | Optional capability; required for enabled internal route, Worker secret.                                                                                                  |
| `FILES_REQUIRE_SCAN`, `FILE_SCAN_WEBHOOK_SECRET`                                         | gated file access and external scan callback                   | Optional; enable only with approved scanner and clean inventory.                                                                                                          |
| `CHROME_EXTENSION_ID`                                                                    | scoped Chrome client identity                                  | Deferred client compatibility; keep existing production setting unless separately authorized.                                                                             |
| `ASSETS`, optional `IMAGES`; gateway `INCORA_PEOPLE`                                     | Worker static/optimization pipeline; Pages Service Binding     | Generated Worker/platform configuration; Pages target production, not a new datastore.                                                                                    |
| `WRANGLER_LOG_PATH`, `WRANGLER_WRITE_LOGS`, `MINIFLARE_REGISTRY_PATH`, `CODEX_SANDBOX`   | build and local sandbox/preview tooling                        | Local; avoid copying logs or changing personal machine config.                                                                                                            |

Check `vite.config.ts`, `lib/runtime-config.ts`, `worker/index.ts`, and `modules/files/` when adding settings. The archive's .env.example is local-safe. Get authorization through private Git and the owner's organization secret-management process. No secret was read from infrastructure in this handoff; only metadata and safe public configuration were inspected. No dedicated staging credentials were verified.
