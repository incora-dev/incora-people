# Rollback and recovery — separately authorized

1. Capture current/previous Worker versions and confirm schema and binding compatibility. Identify whether this is a Worker, Pages, data, or OAuth/DNS incident. Stop risky actions and preserve evidence.
2. For a verified code-only regression, an owner-authorized operator can run `npx wrangler rollback <KNOWN_GOOD_VERSION> --name incora-people` after confirming the installed Wrangler help and correct account. Check new deployment traffic allocation and repeat read-only smoke. [Cloudflare Worker rollback documentation](https://developers.cloudflare.com/workers/versions-and-deployments/rollbacks/) describes retention, binding limits and cached asset/version skew. Rollback does not reverse D1 changes or R2 writes. Separate Pages gateway rollback requires its own verified deployment, authorization and checks.
3. If schema changed, do not presume prior code works. Coordinate compatibility assessment and an approved forward fix or restoration plan. Do not apply arbitrary down migrations. A D1 Time Travel restore, if supported by the production database, is a separate destructive point-in-time operation that can discard later writes. Review the [D1 recovery documentation](https://developers.cloudflare.com/d1/reference/time-travel/) and verify plan/retention and bookmark with the authorized owner.
4. For planned recovery, use private D1 export plus independent R2 protection. An app JSON backup is a business snapshot and object-key manifest, not a byte-for-byte SQL/R2 backup. Keep private exports out of Git and handoff files, hash them, and validate schema-first restoration into disposable infrastructure before considering any production restore. The local script `npm run test:backup-restore` runs an in-memory reconstruction from a supplied scrubbed snapshot when available; see historical `docs/backup-recovery-ua.md` for the prior procedure, not automatic authorization.
5. Do not compensate by replaying emails or announcements. DNS, OAuth and provider credentials are separate recovery workstreams and require owner approval.
