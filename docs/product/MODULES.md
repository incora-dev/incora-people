# Web feature map

**Implemented** means code exists; **tested** denotes relevant automated coverage in this snapshot, not every flow. **Deployed** means known web release scope, not equivalence with every local file. **Live verified** in this handoff covers anonymous smoke only. **Partial** indicates a specific missing verification or functionality. See [current status](../project/CURRENT_STATUS.md) and [route inventory](ROUTES.md).

| Module and UI                                                                    | Main API/domain and data                                                                                                                                             | Permissions, integrations and verification                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Home dashboard, search, calendar and resources: `/`, `/calendar`                 | Dashboard queries, `/api/search`, admin home events/links, company events/links; date and visibility helpers                                                         | Signed-in scoped reads; permissions for events/links edits. Implemented/deployed; automated source/domain checks; full signed-in browser not re-run.                                                                                                                                       |
| People directory and profiles: `/employees`, `/employees/[id]`                   | Employee list/search/sorts, CSV import/export, create/edit/access/termination; `/api/employees/*`; employees, users, references, employment history and terminations | Directory DTO separate from private data. Management, sensitive access and exports server scoped. Implemented/tested/deployed; archived inactive and employment logic distinct from access/deletion.                                                                                       |
| Personal data, contacts, job/skills/certifications                               | Profile tabs and records, media, profile details; `/api/employees/[id]/profile-records`, `/media`; employee private details, profile records, employment history     | Self and policy/manager scope (field-specific); not all records editable by employee. Tests: database integration, profile privacy, security release review. Full role-by-role UI revalidation pending.                                                                                    |
| Compensation and employee documents                                              | Dedicated profile tabs and employee compensation/reveal/documents APIs, private file downloads; compensation and stored files, employee document folders             | Sensitive and reveal rules independent of directory. R2 protection and D1 audit. Implemented/tested/deployed, not a verified external payroll integration.                                                                                                                                 |
| Organization, positions, teams and reporting: `/org`, `/teams`                   | Org units, active reference values, employment types, reporting settings and admin APIs                                                                              | Signed-in structure; admin/policy writes and cycle prevention. Integration tests cover reference constraints.                                                                                                                                                                              |
| Employee access, eligibility and safe deletion                                   | Account access and employee DELETE; protected admins, users, revocable web/client sessions, audit events                                                             | Super Admin safeguards, fresh auth, typed confirmation, real-record blockers and atomic D1 transaction. Isolated eligible/ineligible deletion and FK checks; no real production deletion test. Implemented/tested/deployed.                                                                |
| View as Employee                                                                 | `/api/view-as`, `/api/view-as/exit`, dedicated expired/unavailable pages                                                                                             | Super Admin approved target, read-only session binding, strict route controls and throttles; no expansions on unsupported routes. `view-as.test.mjs` and Worker checks.                                                                                                                    |
| Leave and holidays: `/leave`, calendar                                           | Requests, exports, balances, types and holiday settings; leave days, ledger, balance triggers                                                                        | Employees request own leave; approvals scoped by policy/management. Tests include overlap, holidays, balance, transitions. Deployed; anonymous smoke cannot verify approvals.                                                                                                              |
| Time, break, work mode, timesheets, projects: `/time`, `/time/team`, `/projects` | Clock/toggle, entries, correction/approval, schedules, periods, exports, work mode and project APIs                                                                  | Self-service timer, scoped manager/admin timesheets, locked-period and single-open constraints; D1 histories. Tested in integration; deferred clients not release targets.                                                                                                                 |
| Reimbursements: `/expenses`                                                      | Reimbursement request APIs/policies, approvals and private receipts                                                                                                  | Employee-owned requests; scoped policy approvals. R2 receipt access guarded. Implemented/tested/deployed.                                                                                                                                                                                  |
| Tasks: `/tasks`                                                                  | `/api/tasks` (and id route), people tasks with assignees                                                                                                             | Ownership or authorized task-management scope; employee task action constraints. Domain/integration tests, not a general project management system.                                                                                                                                        |
| Assets: `/assets` and profile workspace                                          | `/api/assets`, company assets and asset events                                                                                                                       | Auth-scoped self/management surfaces, assignment history and batches. Inventory count system is separate. Tested/deployed.                                                                                                                                                                 |
| Office inventory: `/inventory`                                                   | `/api/inventory`; categories, location stocks, counts/lines, corrections, movements, catalog events                                                                  | Super Admin and HR with manageInventory for mutation, read-only preview. Explicit scope, blank-versus-zero and immutable movement audit tested. Full business workflow browser recheck remains separate.                                                                                   |
| 1:1: `/one-on-one`                                                               | `/api/one-on-one`; cadence rules, plans, meetings, conversation notes and recipients                                                                                 | Role/scope-specific planning, note ownership, visibility and recipient rules. V2 migrations/tests deployed; do not infer every privacy/UI workflow is live verified.                                                                                                                       |
| Knowledge and company documents: `/knowledge`, `/documents`                      | Knowledge articles/sections/attachments, document folders and company documents, shared files service                                                                | Signed-in readers with article/attachment audience gates; admin writes. Integration tests include file authorization; storage lifecycle/restore not fully exercised live.                                                                                                                  |
| Announcements: `/announcements`, detail and home                                 | Admin CRUD/publish, images/polls, recipient engagement/dismissal, D1 announcement deliveries                                                                         | Admin publishing, authenticated scoped readers; rich text sanitization and HTML escape tests. Delivery bounded by claim/recipient logic. Website deployed; full inbox/Chat delivery not re-run.                                                                                            |
| Email, Google Chat and user notifications                                        | Internal announcement delivery, scheduler, in-app notifications; Resend adapter, optional legacy webhook, Chat transport; D1 delivery rows/outbox                    | Scoped normal vs admin test paths, no blank admin replay; preview distinct from publication. Local adapter/mocked tests; provider binding existence only in this handoff.                                                                                                                  |
| Employee invitation and preview                                                  | `/api/employees/[id]/invitation`; two `/api/admin/home/*-email-preview` routes; invitation attempts and audit                                                        | Real invite uses eligible enabled employee account and ordinary Google login; Super Admin test sends fixed recipient and shares global 15-minute throttle, without employee/invitation writes. Tests cover idempotency/templates/security. Local copy/email color improvements unreleased. |
| Admin, audit and backup: `/settings`, `/audit`                                   | Admin policies, accounts, holidays, reference data, integrity, backup/export, bug queue; system settings and audit events                                            | Settings/manageSettings plus specific policy and protected Super Admin constraints; audit only if permitted. No authorization implied by UI or handoff.                                                                                                                                    |
| Personal settings, login and public legal pages                                  | `/profile/settings`, preferences/locale; `/login`, Google auth/logout and public `/about`, `/privacy`, `/terms`                                                      | Settings are account-owned; no public onboarding or auto-provisioning. Login and privacy returned 200 live, protected data 401 without auth. Google Console ownership unverified.                                                                                                          |
| Bug reporting, mini-game and roadmap                                             | Global bug dialog/admin queue and screenshot R2; `/api/game-scores`, leaderboard D1; `/roadmap` displays planned features                                            | Signed-in reporting, scoped administrative resolution, isolated from email test routes. Tested source exists; in-product roadmap is historical intent, not current launch authority.                                                                                                       |
| Mobile/extension shared API                                                      | `/api/v1/*`, PKCE and scoped tokens, app/mobile and extension sources                                                                                                | **DEFERRED / ARCHIVED, release scope excluded**, see deferred note. No App Store/Chrome-store readiness claim.                                                                                                                                                                             |
