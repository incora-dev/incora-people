## Source differences

SOURCE-SNAPSHOT.json lists exactly which included originals were normalized for safe transfer. Identifying fixture literals (not schema structure), the local env example, and historical markdown were sanitized; a few assertions that depend on fixture identities were sanitized consistently. Legacy migration filenames are unchanged because Wrangler tracks names; obtain immutable historical versions via authorized private source before real migrations. Fixed recipient business configuration and public production metadata are preserved where required for code semantics. The debug Android keystore, prior extension ZIP, optional local binaries and build outputs are excluded. Source can be built without them. No native session files or Git history were bundled.
